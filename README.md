# One Line, Zero Use: The Useless Superpower Sprint


One original line, at most 200 characters, naming a hilariously useless superpower.


> I can stop time, but only while I'm asleep, so I wake up exactly as late as ever.


`main.py` prints exactly that line and writes it to `/output/entry.txt`, the artifact the judge reads. No code, no setup, nothing else submitted.


Entry for the make.fun bounty "One Line, Zero Use: The Useless Superpower Sprint" (https://make.fun/bounty/u-daring-gecko-25-one-line-zero-use-the-useless-01ca1c68).
